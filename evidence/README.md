# Evidence snapshots

Algorithm cards in `src/chemflow/cards/data/` cite these files by path and
SHA-256, and `chemflow.cards.validate_cards` checks both the hash and the quoted
text. The reports are kept verbatim from the `hybrid-pulse-chemistry` project:
editing them would break the hash, so their relative links to figures, CSV files,
run directories and review notes point into that project and are not included
here.
